# What's on this box

| Address | What it is |
|---|---|
| <https://deck> | Dashboard — every service, with a live status dot |
| <https://wiki.deck> | Wiki — offline encyclopedias and documentation (Kiwix) |
| <https://vault.deck> | Passwords — offline password manager (see [Passwords](passwords.html)) |

These addresses work on this box itself. Reaching them from other devices
(phones, laptops) comes with the planned Wi-Fi hub mode.

Your account is called `deck`; its password is the one you chose at the
first start (the desktop logs in automatically).

**Logins that want an email address.** Some services ask for an email address as your
login name, but this box sends no email. Use your name followed by `@` and the service's
address — e.g. **`anna@vault.deck`** for Passwords. It only has to *look* like an email.

The wiki ships with: the **Arch Wiki** (general Linux help), **man pages**,
**Nix**, **bash** and **git** references, and this manual.
